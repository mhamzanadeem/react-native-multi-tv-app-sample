# Licensing and provenance

- The repository already contains the MIT No Attribution (MIT-0) license in `LICENSE`. Its original Amazon copyright notice is retained without alteration.
- MIT-0 expressly permits copying, modification, distribution and sale. A public open-source license is not an anti-copy restriction. Adding a second MIT license would not provide one.
- The original Amazon multi-TV sample, third-party libraries and FormFit-specific additions must be described accurately; a fork is not a claim of ownership over its upstream code.
- Dependencies and any third-party media retain their own licenses and terms. Review rights to demo footage, audio and media before submission; the source license does not automatically license unrelated media.
- The FormFit logo was generated for this project with imagegen; its prompt and asset locations are documented in `docs/branding.md`. No claim of trademark clearance or exclusive copyright in generated artwork is made.
- The hackathon rules allow a public repository with an open-source license or a private repository shared with the required reviewers. The Open Source mini-challenge requires an open-source contribution. Check the current [official rules](https://amazonappdev2026.devpost.com/rules) and [FAQ](https://amazonappdev2026.devpost.com/details/faqs).
- A different license for independently owned future work would require an explicit scope decision; it cannot revoke rights already granted for the upstream sample. No license replacement or new copying restriction was applied in this update.
