# FormFit TV branding

Generated with the built-in imagegen tool. The original output is retained in `packages/shared-ui/src/assets/branding/formfit-logo-master.png`. The shared UI uses `formfit-logo.png`. Launcher, favicon and TV banner sizes are in `apps/expo-multi-tv/assets/branding/` and referenced by Expo configuration.

Prompt: Create a polished square app icon for FormFit TV. A single original geometric emblem combines a dynamic letter F and a subtle dumbbell/movement motif, centered with generous safe margins. Electric cyan and periwinkle on midnight navy #080D20, restrained glow, crisp silhouette readable at 32 pixels. No wordmark, mockup, border or tiny details.

The launcher and TV banner changes require a new native build/install; Metro refresh alone only updates in-app branding. Native generated Android/iOS folders remain excluded from Git. Existing generated resources are not hand-edited.

Artwork sizes are packaging derivatives of the generated master. TV banners include a readable FormFit TV wordmark. No remote image URL or credential is needed to display the logo.
